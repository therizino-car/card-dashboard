# card-dashboard

카드별 **실적·혜택 현황**을 보여주는 정적 대시보드예요. `index.html` 한 파일(외부 라이브러리 없음, 바닐라 JS)로 되어 있어요.

- 데이터는 이 저장소에 **없어요.** 구글 로그인(Google Identity Services, OAuth 토큰) 후 브라우저가 본인 구글 드라이브의 시트를 **읽기 전용**으로 직접 불러와요.
- 요청 권한: `drive.readonly`, `spreadsheets.readonly`
- 로그인 전에는 아무 데이터도 보이지 않아요.

## 구조

```
구글 드라이브
└─ 카드 실적·혜택/                (FOLDER_ID)
   ├─ 카드 실적·혜택 2026-10      (월별 스프레드시트)
   ├─ 카드 실적·혜택 2026-11
   └─ ...
GitHub Pages
└─ index.html  → 폴더 안 월별 파일 목록 → 월 선택 → 시트 3개 탭 읽어서 표시
```

## 월별 시트 양식 (1행은 헤더, 순서 고정)

| 탭 | 열 |
|---|---|
| 요약 | 카드, 전월 실적, 전월 구간, 이번달 예상 실적, 현재 구간 목표, 다음 목표, 다음 목표까지 부족액, 실적 충족, 혜택 받은 합계, 혜택 한도 합계, 혜택 충족, 상태그룹, 비고 |
| 혜택 | 카드, 혜택 항목, 받은 금액, 최대 한도, 남은 한도, 조건·메모 |
| 내역 | 날짜, 카드, 항목명, 금액, 계정그룹, 계정, 메모, 실적 인정(O/X), 제외 사유, 예상 혜택 |

- `상태그룹`: `모두 충족` / `실적 또는 혜택만 충족` / `모두 미충족` / `관리 안 함`
- `실적 충족`, `혜택 충족`, `실적 인정(O/X)`: `O` 또는 `X`
- 숫자 열은 숫자로 입력(서식 `#,##0`). 비어 있으면 화면에 '미입력'으로 나와요.
- 파일 이름은 반드시 `카드 실적·혜택 YYYY-MM` 형식이어야 목록에 나와요.

## 설정 방법

1. Google Cloud 콘솔에서 프로젝트를 만들고 **Google Drive API**, **Google Sheets API**를 사용 설정해요.
2. OAuth 동의 화면: 외부 / 테스트 상태, 범위 `drive.readonly`·`spreadsheets.readonly`, 테스트 사용자에 본인 계정 추가.
3. 사용자 인증 정보 → OAuth 클라이언트 ID → **웹 애플리케이션**. 승인된 JavaScript 원본에 `https://therizino-car.github.io` 추가.
4. 발급된 ID를 `index.html` 맨 위 `CLIENT_ID`에 넣고 커밋해요. (`FOLDER_ID`는 드라이브 폴더 URL의 마지막 부분)

클라이언트 ID는 비밀값이 아니에요. 승인된 원본과 테스트 사용자로 접근이 제한돼요.
